Historical test blocks are preserved as evidence, not re-executed or independently re-proven. Link/heading checks are static and cannot establish semantic or production PASS alone.

`python3 tools/audit_documents.py --summary` checks all Markdown relative link destinations/headings and historical-body hashes. The final report is also included in that scan. GitHub publication and exact deployed scheduler version are release gates recorded on the merging PR; a local audit alone does not satisfy them.
